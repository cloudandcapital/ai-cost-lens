How this works and what the terms mean

Ready result = finished work that met the same stated quality rule on both routes.

Full recurring cost = provider spend + shared infrastructure included in the review + human review and correction.

Cost per ready result = full recurring cost ÷ results that met the quality bar.

Evidence check = the required cost, quality, policy, and coverage checks that must agree before a difference can be called savings.

Finance recommendation = fund the change, fix the evidence, stop the change, or report insufficient evidence. It is bounded to this review.

Observed logs, samples, estimates, and missing evidence remain visibly different. A sampled or user-estimated result cannot become proven savings.

    Advanced cache assumptions

    Cached input is treated as a repeated prefix. Add refreshes only when the provider publishes a separate cache-write rate. A refresh replaces one cache-read call; it is not added on top of the same call.

    For explicit caches, token-hours equal cached tokens multiplied by retained hours across the month. Separate storage cost is added only where the provider publishes that rate. Zero means storage is excluded, not free.
