# Pricing catalog refresh — October 18, 2026

Catalog: `web/data/pricing-catalog-v0.5.js`, version `2026-10-18`. The prior 21-record catalog is preserved byte-for-byte at `pricing-catalog-2026-10-11.js`. This snapshot contains 22 records: 20 current comparison choices and two historical Gemini aliases. The review deadline stays November 21, ahead of OpenAI's published promotional guarantee and Google's December rate boundary.

All figures are direct paid Gemini Developer API USD per million text tokens. The calculator excludes negotiated or partner-cloud prices, grounding and other tool calls, taxes, and any charges not entered. It never treats an estimated comparison or request-log reprice as realized savings.

## Gemini 4 Argon

- [Google announced general API availability](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/) on October 13. The stable ID is `gemini-4-argon`; the [model page](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon) was updated October 14.
- [Direct API pricing](https://ai.google.dev/gemini-api/docs/pricing), checked October 18: Standard input $2, implicit cache read $0.10, output $10; Batch and Flex $1/$0.05/$5; Priority $3.60/$0.18/$18. Output includes thinking tokens. Explicit cache writes and cache storage do not apply. A cached prefix must contain at least 4,096 tokens. The [migration guide](https://ai.google.dev/gemini-api/docs/latest-model) also describes this minimum and the implicit-only cache.
- All those introductory token rates double on December 1, 2026. This catalog discloses that scheduled change but intentionally rejects estimates from December 1 until a newly verified snapshot is shipped. Annualization crossing November 30 is withheld. The catalog review deadline, November 21, comes first.
- Google publishes one unified context budget of 1,048,576 tokens for input plus thinking and output. The ordinary synchronous output maximum is 65,536. Background long decode can exceed 65,536, but the calculator does not represent that execution mode, so it rejects larger output counts. The [model page](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon) and [token guide](https://ai.google.dev/gemini-api/docs/tokens) establish these limits.
- This entry permits the global direct Developer API only. No separate geography premium is published on the checked pricing page. The invite-only Contributor tier, which uses submitted content to improve Google's products, is excluded; the ordinary paid tier states content is not used for that purpose. Grounding with Search or Maps can add per-query charges and is excluded from the token estimate.

The old models and their historical rates remain intact. The Price a Prompt to Review handoff now names the calculator-sourced rates and volume separately from the missing output-quality and human-effort evidence; the standalone example keeps its example caveat. Tests cover the pricing modes, release and rate-change dates, cache and context limits, historical catalog selection, request-log repricing, savings gate, and both browser paths.
