Current catalog: 21 records, including two historical Gemini aliases; 19 current choices. Review again by November 21, 2026, the published minimum guarantee date for GPT-5.6 Sol promotional pricing. All token rates below are direct API USD per million tokens. The catalog excludes negotiated and partner-cloud pricing, taxes, grounding, server-side tools, and unentered charges. No estimated calculator or request-log amount is evidence of realized savings.

## Anthropic

- [Release notes](https://platform.claude.com/docs/en/release-notes/overview) dated October 7: Claude Sonnet 5.5 cache reads fell from $0.20 to $0.10; other prices did not change. Standard input/output remain $2/$10; 5-minute and 1-hour cache writes remain $2.50/$4. Batch cache reads fell from $0.10 to $0.05. The engine selects the prior read rates through October 6 and the new rates from October 7, with the rate effective date recorded in the estimate. Historical annualization crossing the known price change is withheld.
- [Claude Haiku 5.5](https://platform.claude.com/docs/en/models/haiku-5-5/overview) launched October 7 with ID `claude-haiku-5-5`, a 1M context and 128K standard max output. [Direct API prices](https://platform.claude.com/docs/en/about-claude/pricing): through 100,000 prompt tokens, input $0.10, output $0.50, cache read $0.01, 5-minute write $0.125, 1-hour write $0.20. Above 100,000, the *whole request* is charged input $0.50, output $2.50, read $0.05, 5-minute write $0.625, 1-hour write $1. The threshold includes all input, including cache reads and writes. Batch token rates are 50% of Standard. US-only inference adds 10% to every token category. A cacheable prefix must be at least 512 tokens; otherwise the calculator rejects an assumed cache hit. Haiku 5.5 uses a newer tokenizer and may count roughly 30% more tokens for the same text than Haiku 4.5, so a shared manual token count remains an estimate.
- The special 300K Batch output beta, partner-cloud charges, and tool charges are outside this catalog.
