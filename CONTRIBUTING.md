# Contributing

Contributions are welcome. Please open an issue before submitting a pull request so we can discuss the change first.

Keep pull requests focused on one feature or fix. Run the existing tests with `pytest` and follow the code style already used in the project.

For new provider support, add a sample CSV in `examples/`, extend the detector in `ai_cost_lens/providers/detector.py`, and include tests for detection and normalization.

By submitting a pull request, you agree to license your contribution under the project's MIT License.
